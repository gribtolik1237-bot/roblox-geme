# TRAP LAB (Лаборатория ловушек) — Roblox

Игроки строят трассы-полосы препятствий на своих участках, NPC-испытатели проходят их и приносят монеты, игроки проходят свои и чужие трассы. Rebirth, Daily, рейтинг трасс, «Зал» с досками лидеров, донат (только косметика), до 8 игроков на сервере.

- Место в Roblox: «Лаборатория ловушек», PlaceId `135937017652181`, UniverseId `10776882597`.
- Код и мир живут **внутри места** (без Rojo). Папка `place/` в этом репозитории — выгрузка скриптов из места (если её ещё нет, значит выгрузка ждёт; см. `claude/README.md`).

## Где что лежит

| Папка | Что внутри |
|---|---|
| `docs/` | Вся документация проекта. Начинать с `HANDOFF.md` (последний раздел), затем `REPORT_AUDIT_S8.txt`, `TASKS.md`, `TESTING_REPORT.md`, `BUG_TRACKER.md`, `DECISIONS.md`, `ART_DIRECTION.md`, `BALANCE.md`, `ASSET_REGISTRY.md`. Промт для нового чата — самый свежий `NEXT_CHAT_PROMPT_S*.md`. |
| `spec/` | Исходное ТЗ владельца (`промт роблокс игры.txt`) и мастер-аудит (`промт на исправления ошибок.txt`). |
| `assets/` | Исходники ассетов: Blender-скрипты и рендеры иконок, звуки, текстуры, картинки для доната. |
| `references/` | Эталоны дизайна владельца: `owner_examples/` (6 PNG «не нейрослоп»), `session5/` (3 референса UI). |
| `claude/` | Память и правила работы ассистента по этому проекту (`memory/*.md`) и инструкция `claude/README.md`. |
| `place/` | Скрипты места по дереву Studio: `ServerScriptService/…`, `ReplicatedStorage/…`, `StarterPlayer/…` (файлы `.server.luau`, `.client.luau`, `.luau`). |

## Главные правила владельца (кратко; полностью — в промте и `claude/memory/`)
- Без «нейрослопа» и без дерева; цветной пластик со studs, толстый контур, цвет = роль.
- Магазины — компактные киоски с одним продавцом; обучение — только стрелки.
- Верхние кнопки Shop / Home / NPC Shop — только телепорт; окна модальные.
- Забег PLAY — первое лицо, одна кнопка Exit.
- Цены доната без владельца не менять; отчёт честный: PASSED / NOT TESTED / FAILED.
