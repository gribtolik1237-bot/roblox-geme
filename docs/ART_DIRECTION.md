# ART_DIRECTION — TRAP LAB (по скиллу game-art-direction; обновлено 2026-))-)6 по эталонам владельца)

Контекст: игра про «лабораторию ловушек»: испытательный полигон, где игроки строят полосы препятствий, а NPC-испытатели их проверяют.
Стиль мира следует из этого сюжета И из эталонов владельца (см. «Эталоны»). Прошлую игру (Crystal Rush) как референс НЕ используем.

## Эталоны (6 скриншотов владельца: папка «примеры современного дизайна который не неерослоп»)
Что ВИДНО на эталонах (факты, не мои предположения):
). **Форма и силуэт.** Постройки «сложены из кирпичей»: прилавок с полосатым навесом, по бокам толстые столбы, НАД навесом стоит доска-вывеска (силуэт «навес + доска» читается издалека). Арка/тоннель — концентрические ступенчатые рамки. Забор — тёмные столбы + рыжие X-раскосы. Машина — купол, трубы, светящийся экран. Лидерборд — толстая светло-голубая рамка с фаской вокруг тёмного списка, на ножке-постаменте.
2. **Палитра и роли.** Очень насыщенная, но с одним базовым тоном: яркий зелёный газон (два тона шахматкой), голубое небо с облаками, тёплые охристо-коричневые стены, тёмно-красное дерево каркасов. Навесы — пары «акцент + светлая лаванда/белый». Цвет = роль: бирюзовое кольцо на земле = торговля, жёлтое = зона/старт, зелёная кнопка = «Магазин», голубая = «Индекс».
3. **Типографика.** Плотный закруглённый жирный гротеск, КРУПНЫЙ, у всего текста толстая тёмная обводка. Заголовок вывески — белый на тёмно-красном; цветные заголовки (жёлтый/красный/голубой) только поверх обводки. Числа валюты — крупные, цветные, слева значок. 2–3 размера на экран, главный — в 2–3 раза крупнее подписи.
4. **Материалы и детали.** На КАЖДОЙ плоскости микрорельеф: шипы (studs) на плитах и кирпичах, фаска по краям, вставки. Нет плоских одноцветных плит. Глянец только у сундука/кнопок (функциональный акцент).
5. **Свет.** Яркий дневной, мягкие тени, небо видно, облака. Нигде нет тёмной «коробки», кроме проёма тоннеля.
6. **Интерфейс.** Слева стопка КРУПНЫХ плашек (иконка слева + название), плоская яркая заливка с тёмным контуром и лёгким градиентом, красный бейдж-счётчик. Сверху по центру — баннер события (иконка + заголовок + таймер). Справа — вертикальные квадратные плитки-иконки с цветной рамкой. Слева-снизу — валюта: иконка + крупное число. Снизу по центру — хотбар из тёмных полупрозрачных квадратов с номерами. Иконка крупнее плашки и выступает за её край. Интерактивные зоны на земле отмечены светящимся кольцом. Плотность средняя, группы разделены.
Вывод: цель — «яркий кирпичный полигон»: тёплая насыщенная палитра, шипы+фаски на всём, толстые обводки текста, крупные иконки. НЕ «графит + неоновая кромка» (это и называется нейрослоп).

## Форма и конструкция
- Архитектура: прилавки/павильоны с каркасом из толстых столбов, навес в двух цветах, вывеска-доска НАД навесом. Бетон/плитка → «плитка с шипами» и «кирпич».
- Каждая постройка читается силуэтом издалека и имеет посадку: столбы стоят на опорных плитах, панели лежат в каркасе, вывеска — на стойках.
- Любая «плита» получает: фаску-кромку другого тона, шипы (Plastic + TopSurface Studs) или материал с фактурой (Pavement, Brick, WoodPlanks, Slate), стык/шов.

## Материалы
- Земля лобби/участка — живая трава (Grass) яркого зелёного; площадь вокруг построек — плитка Pavement/Plastic с шипами.
- Дерево — каркасы, прилавки, столбы (WoodPlanks / тёмно-красный Brick). Металл — только маленькие детали (крепёж, лампы).
- Neon — только крошечные функциональные акценты (лампа на вывеске, кольцо интерактивной зоны). Никаких неоновых полос как отделки.

## Цветовые роли
- Бренд TRAP LAB / опасность: сигнальный жёлтый (255,)96,40) + графит ТОЛЬКО как hazard-кромка небольшой площади.
- Obstacle Shop — бирюзовый; NPC Shop — фиолетовый; PLAY/старт — зелёный; Rebirth — пурпур; опасность/ошибка — красный; цвета редкостей — только для редкостей.
- Базовые тона мира: трава (96,)90,72), песчаная плитка (232,205,)50), тёмно-красное дерево ()50,62,50), вода-бассейн (50,)70,200).

## Типографика и интерфейс
- Один шрифт-семейство: Builder Sans (ExtraBold — заголовки/кнопки, Bold — текст; кириллица поддерживается). У всего крупного текста — тёмная обводка (UIStroke 2–3 px) для читаемости на любом фоне.
- Кнопки: плоская яркая заливка + НИЖНЯЯ «губа» темнее (глубина), тёмный контур, иконка слева; состояния: обычное / наведение (светлее + масштаб) / нажатие (проседание) / недоступно (серая + замок). Без «стеклянных» глянцевых градиентов на всю высоту.
- Окна: тёмная подложка, цветная шапка с названием, крупные карточки; один главный акцент на экран.

## Свет
- Дневной «золотой час» мягче: ClockTime ~)5, облака, голубое небо; дымка минимальная; цветокоррекция слегка тёплая. Тени читаются, нет белых засветок.

## Критерии приёмки (проверять по скриншотам)
). Силуэт каждой постройки узнаётся издалека. 2. Нет неоновых полос-отделок. 3. Нет плоских одноцветных плит: у каждой — шипы/фактура/фаска. 4. Текст читается на реальном фоне и размере (обводка). 5. Все вывески одного семейства. 6. Нет повторяющегося шаблона «просто другой цвет». 7. Сверка с эталонами по пунктам )–6 выше.

## Журнал визуального прохода
- 2026-))-)6, ДО правок (скриншоты Studio): (a) «Зал» — тёмные синие плиты с неоновыми кромками (голубая/розовая/жёлтая) и мелким текстом — типичный нейрослоп, нет объёма и деталей; (b) участки — тёмно-синие плоские прямоугольники 72×96 с неоновой голубой окантовкой на бурой гальке — читаются как «дыра», без деталей; (c) лобби — огромное бурое поле без ориентиров, небо с серо-розовой дымкой; (d) Obstacle Shop — удачнее остальных (навес полосами, полки), но пол плоский серый, столбы тонкие без опор-башмаков, нет шипов/фаски.
