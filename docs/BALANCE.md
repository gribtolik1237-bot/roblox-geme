## Награды — ручное прохождение
`reward = (Flat 20 + 12 * stages) * DifficultyMult` (Easy 1.0, Normal 1.5, Hard 2.2, VeryHard 3.2, Extreme 4.5), максимум 2500.
Первое прохождение версии трассы — 100% (чужая) / 50% (своя); повторы — 0. Создатель получает 25% (кап 3000/день).

## Награды — NPC
Этап: `8 * вес_препятствия * затухание_одинаковых * затухание_повторов`; бонус финиша: `30 + 40%` накопленного.
Повторы на той же версии: -15% за попытку в окне 1 ч, не ниже 25%. Низкое качество трассы (<4 этапов или <3 типов): x0.3.

## Daily Challenges
Система ежедневных испытаний и её множители Coins сняты в версии 206 по решению владельца. Ежедневный подарок за вход выдаёт `LoginRewardService`.

## Характеристики NPC (1..10) -> движение
WalkSpeed = 10 + 1.2*Speed; JumpPower = 38 + 2.6*Jump; Balance: боковое покачивание sigma=(11-Balance)*0.12; Control: ошибка руления sigma=(11-Control)*0.08 и ошибка тайминга прыжка (11-Control)*0.03 с; Recovery: шанс восстановления = Recovery/12.


## История ежедневных испытаний (ТЗ 14, снято в версии 206)
Источник чисел: `Configs/Balance.lua` -> `Balance.Daily`. Сервис: `DailyService`.
| Сложность | Название | Множитель | Длительность | Цель | Какие трассы считаются |
|---|---|---|---|---|---|
| Easy | Warm-up | x2 | 10 мин | пройти 1 трассу | любая (в т.ч. своя) |
| Hard | Courage | x2 | 20 мин | пройти 2 трассы | только ЧУЖИЕ, сложность Normal и выше |
| Super Hard | Nightmare | x3 | 15 мин | пройти 3 трассы | только ЧУЖИЕ, сложность Hard и выше |

- Испытание НЕ платит Coins: награда — только множитель. Умножаются **только существующие** источники (`RewardService.MULTIPLIABLE`): ручное прохождение (`manual`), этапы NPC (`npcStage`), бонус финиша NPC (`npcFinish`). Доля создателя трассы (`creator`) **не** умножается.
- Итог = `floor(награда * множитель)`; округление вниз, каждая выдача идемпотентна (ключ в `profile.paid`).
- Бонусы не складываются: при новом бонусе берётся лучший множитель и более долгий из (новый срок, остаток старого).
- Прогресс считается только с момента принятия, одна и та же версия чужой трассы засчитывается один раз за попытку.
- Cooldown: один раз на сложность за серверные сутки (UTC, `ResetUtcHour = 0`). Смена дня считается по `os.time()` СЕРВЕРА; часы устройства не влияют. Состояние (`profile.daily`) сохраняется: переподключение не применяет бонус повторно (`done[tier]` ставится ДО выдачи бонуса).

## Рейтинг трасс (ТЗ 16)
Сервис: `RatingService`, настройки `Balance.Rating`. Критерии (по ТЗ): Interest, Build quality, Difficulty, Variety, Overall. Шкала: целые 1..5.
- Оценивать можно только ПОСЛЕ прохождения текущей версии трассы, чужую трассу, раз в час менять (`RatingEditCooldown = 3600 с`); изменённая оценка ЗАМЕНЯЕТ прежнюю (n не растёт).
- Показываемое значение = `(Σ средних по пяти критериям у каждого проголосовавшего + 3*5) / (N + 5)` (байесовское среднее, априор 3 звезды весом 5 голосов): мало голосов не даёт крайних значений. Не более 150 голосов на трассу.
- «Популярные трассы» = онлайн-трассы, отсортированные по формуле TOP OBBY.

## Лидерборды (ТЗ 15)
Сервис: `LeaderboardService` (OrderedDataStore, имена `TrapLab_TopMoney_v1`, `_TopRebirths_v1`, `_TopObby_v1`; в Studio с суффиксом `_STUDIO`), доски в лобби — `HallService`.
- TOP MONEY = текущее число Coins; TOP REBIRTHS = число Rebirth; запись не чаще раза в 90 с на игрока и только при изменении; чтение с кэшем 60 с; топ-10.
- TOP OBBY = `10000 * Σ(вес_i * норма_i)`, каждая норма в [0;1] и ограничена капом:
  | Критерий | Вес | Норма |
  |---|---|---|
  | Качество трассы | 0,20 | `0,5*min(этапы/8,1) + 0,5*min(типов препятствий/5,1)`, при низком качестве x0,3 |
  | Успешные прохождения (чужие) | 0,20 | `min(clears,50)/50` |
  | Популярность (запуски чужими) | 0,15 | `min(plays,100)/100` |
  | Оценки игроков | 0,20 | `clamp((рейтинг-3)/2, 0, 1)` — без голосов 0 |
  | Сложность | 0,10 | `номер сложности/5` |
  | Реальная активность | 0,15 | `min(различных посетителей за 7 дней, 20)/20` |
  Ни один критерий не даёт больше 20% шкалы (требование ТЗ — не более 25%); количество объектов не учитывается; недостроенная трасса = 0.
- Если OrderedDataStore недоступен, доска показывает игроков ЭТОГО сервера и подписана «this server only».

- Размещать можно только на земле владельца вне «коридора» (зона стройки + стартовая платформа + табличка + запас 6), не ближе половины суммы радиусов к другим украшениям. Все части без коллизии и без запросов: не мешают стройке, ходьбе и лучам NPC.
