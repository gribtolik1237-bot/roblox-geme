## 10 НЕЗЫБЛЕМЫХ СТАНДАРТОВ РАЗРАБОТКИ (КРИТЕРИИ ПРИЁМКИ НАЧАЛЬНИКА)

### 1. ГЕЙМДИЗАЙН, ONBOARDING (ПЕРВЫЕ 60 СЕКУНД) И УМНЫЕ БОТЫ
- Строгая опора на docs/ и references/: весь стиль, палитра, механики и UI должны соответствовать документации и референсам из references/.
- Первые 60 секунд: никаких стен текста на старте. Веди нового игрока через интуитивный луч-указатель (Beam к первой цели), мгновенный экшн и первую награду за 15–30 секунд.
- Живой онлайн (Smart Bots): для мультиплеера создавай умных NPC-ботов (PathfindingService, стейт-машина Idle/Patrol/Chase/Attack, рандомный скин), заполняющих сервер при нехватке игроков.
- Итеративность: делай по 1 законченной системе / 1 экрану UI / 1 пакету моделей или звуков за шаг с промежуточной проверкой у начальника. Никаких `-- TODO: сделать позже`.

### 2. 3D-МОДЕЛИРОВАНИЕ (BLENDER CLI + STUDIO), МАСШТАБ И КОЛЛИЗИИ
- Генерация через Blender CLI: если blender доступен, пиши Python-скрипты (bpy) и запускай их в фоне (`blender --background --python ...`), создавая стилизованные low-poly модели с экспортом в .fbx (Scale = 0.01, Apply Transform) в assets/models/. (См. уточнение про Blender MCP внизу: оно приоритетнее.)
- Стандарты 3D-модели:
  - Чёткий силуэт, фаски (Bevel), многосоставная форма (никаких предметов из 2–3 голых параллелепипедов).
  - Лимит полигонов: строго < 10 000 tris на меш (оптимально 500–4 000 tris), Shade Smooth / Auto Smooth.
  - Разделение саб-мешей по цветам/материалам (Separate by Selection) перед экспортом для покраски и назначения PBR-материалов в Studio (SmoothPlastic, Metal, Neon, WoodPlanks, Glass).
  - Контроль масштаба и пола: сверяй габариты (GetBoundingBox()) с ростом R15 персонажа (~5 studs), настраивай PivotOffset и привязывай объекты ровно к полу через Raycast (никаких висящих в воздухе или провалившихся пропсов).
  - Физика мешей: для мелкого декора — Anchored = true, CanCollide = false, CanTouch = false, CanQuery = false, CollisionFidelity = Enum.CollisionFidelity.Box. Для геометрии с коллизией — Hull или PreciseConvexDecomposition.
- Если Blender не установлен: строй детализированные составные модели в Studio (WedgePart, CornerWedgePart, Cylinders, фаски, тримы) с микро-вариацией оттенков цвета.

### 3. КИНЕМАТОГРАФИЧНЫЙ СВЕТ И АТМОСФЕРА (LightingSetup)
- Всегда включай Lighting.Technology = Enum.Technology.Realistic (или Future для закрытых локаций с точечным светом).
- Выстраивай контраст света и тени (Ambient, OutdoorAmbient, ColorShift_Top), настраивай Atmosphere (Density 0.25–0.38, Haze, Glare), BloomEffect, SunRaysEffect, динамические Clouds и ColorCorrectionEffect (Contrast, Saturation, TintColor под настроение из references/).

### 4. GAME FEEL, ПРОЦЕДУРНЫЕ АНИМАЦИИ (SPRING) И VFX
- Мультисенсорный импакт: каждое действие (удар, выстрел, добыча, покупка, апгрейд) = анимация + CameraShake + ParticleEmitter:Emit(N) + хитмаркер + звук.
- Пружинная физика (Spring модуль): процедурные Spring-смещения CFrame / Motor6D для инерции оружия/предметов в руках (Sway при повороте камеры, Bobbing при беге, импульс отдачи), наклона корпуса при беге и динамического Camera.FieldOfView (FOV-рывок при спринте/ударе).
- Профессиональный VFX:
  - Привязывай эффекты к Attachment, запускай точечным :Emit(count) (а не постоянным .Enabled = true), настраивай кривые NumberSequence для Size, Transparency и Squash.
  - Для сильных ударов добавляй Hit-Stop (пауза анимации на 0.04–0.06 с), Impact Frame (вспышка ColorCorrectionEffect на 1 кадр) и волну осколков вдоль LookVector / RightVector игрока с автоочисткой через Debris.

### 5. UI / UX ДИЗАЙН И ТАКТИЛЬНОСТЬ
- Дизайн-система: палитра 60/30/10 по референсам, единые шрифты (BuilderSans / GothamBold / FredokaOne), UIPadding, UIListLayout, UIGridLayout. У всех ScreenGui ставь ResetOnSpawn = false и ZIndexBehavior = Enum.ZIndexBehavior.Sibling.
- Адаптивность под ПК, телефоны и планшеты: только Scale + обязательный UIAspectRatioConstraint + UITextSizeConstraint.
- Техническая чистота:
  - Скруглённые прогресс-бары (UICorner) всегда оборачивай в CanvasGroup (ClipsDescendants = true), чтобы полоска не вылезала за углы.
  - На UIStroke ставь LineJoinMode = Enum.LineJoinMode.Bevel (или Miter) против артефактов на буквах.
  - В ScrollingFrame используй AutomaticCanvasSize = Enum.AutomaticSize.Y или привязку к AbsoluteContentSize.
- Тактильный UIAnimator: MouseEnter → скейл 1.04x + hover SFX; MouseButton1Down → сжатие 0.94x + click SFX; всплывающие числа урона/валюты (Floating Text) с параболической Tween-анимацией.

### 6. ПОЛНЫЙ КОНВЕЙЕР СОЗДАНИЯ ЗВУКОВ, СИНТЕЗА И АУДИО-ИНЖЕНЕРИИ
Автономная генерация и синтез звуков (Python DSP + FFmpeg). Когда проекту нужны звуки, которых ещё нет в assets/audio/, пиши и запускай Python-скрипт (wave, numpy, scipy + ffmpeg), синтезирующий чистые многослойные .wav / .ogg файлы (44.1 kHz, 16-bit):
- Слоение (Layering): собирай каждый SFX из 2–3 слоёв — Sub/Bass (50–150 Hz с быстрым pitch-drop для веса), Mid/Body (200–1200 Hz для характера/аккорда) и High/Transient (5–25 мс отфильтрованного шума или щелчка для чёткости атаки).
- Психология тона (Pitch Envelope) и ADSR: награды/комбо/апгрейды — восходящий питч и мажорные интервалы (1.0 + combo * 0.05); ошибки/урон — нисходящий питч; UI — короткие (25–80 мс) мягкие тактильные клики; эмбиент — бесшовные лупы с кроссфейдом краёв.
- Мастеринг: срез резких ультравысоких частот (Low-Pass < 12 kHz), микро-фейды 5–10 мс в начале и конце (волна начинается и заканчивается строго в 0.0 без щелчков) и нормализация пиков до -6 dB.

Архитектура AudioController и SoundService:
- Включи SoundService.VolumetricAudio = Enum.VolumetricAudio.Enabled и настрой подходящий AmbientReverb.
- Создай в SoundService иерархию SoundGroup (Master → Music, SFX, UI, Ambient, Voice), где громкость групп работает как множитель для настроек игрока, плюс CompressorSoundEffect, EqualizerSoundEffect и ReverbSoundEffect.

3D-позиционирование, Volumetric Zones и Occlusion:
- UI и хитмаркеры — строго локально на клиенте; точечные 3D-звуки — в Attachment/Part с RollOffMode = Enum.RollOffMode.InverseTapered; зональные звуки локаций — через объёмные невидимые Part-зоны (для звука строго внутри комнаты RollOffMinDistance = 0, RollOffMaxDistance = 0).
- Для важных 3D-источников делай проверку workspace:Raycast от камеры до источника (Audio Occlusion) с плавным приглушением высоких частот за стенами и адаптивные шаги (FootstepSystem) по Humanoid.FloorMaterial.

Анти-пулемёт, Sound Pooling и Audio Ducking:
- Пул из 3–5 вариаций + случайный PlaybackSpeed (0.92–1.08) на частые действия, объектный пул переиспользуемых Sound-инстансов, кроссфейд музыки (1.5–2 с), приглушение музыки (Audio Ducking) при важных событиях, единый SoundRegistry.luau и предзагрузка через ContentProvider:PreloadAsync().

### 7. КРОССПЛАТФОРМЕННЫЙ ВВОД (ПК + МОБИЛКИ + ГЕЙМПАД)
Запрещено хардкодить механики только под клавиатуру. Реализуй единый InputController на базе ContextActionService и UserInputService, чтобы каждое действие имело стилизованные сенсорные кнопки на смартфонах/планшетах и работало на ПК/консолях.

### 8. СЕТЕВАЯ БЕЗОПАСНОСТЬ, АНТИ-ЧИТ И БОЕВАЯ СИНХРОНИЗАЦИЯ
Никогда не доверяй клиенту: урон, цены и награды берутся строго из серверных конфигов. Ставь Rate Limiting (os.clock()) на RemoteEvent, а при атаках проверяй на сервере состояние игрока, кулдаун, дистанцию (Magnitude <= maxRange + pingTolerance) и отсутствие стены (workspace:Raycast).

### 9. НАДЁЖНЫЕ СОХРАНЕНИЯ (DataManager) И МОНЕТИЗАЦИЯ
- Серверный DataManager: сессионный кэш, pcall с повторами, автосохранение каждые 60–90 сек, защита от дюпов и game:BindToClose().
- Для покупок за Robux — идемпотентный ProcessReceipt (PurchaseGranted только после сохранения в профиль) и кэширование GamePass.

### 10. ЧИСТЫЙ LUAU, ПАМЯТЬ (JANITOR/TROVE) И САМОПРОВЕРКА
- Модульная архитектура (ServerScriptService, ReplicatedStorage/Shared, StarterPlayerScripts), типизация `--!strict`, только современное API (task.wait, task.spawn, workspace:Raycast, workspace:GetPartBoundsInBox).
- Все подписки (RBXScriptConnection), циклы RunService и твины привязывай к Janitor / Trove. После прохождения финальной приёмки у начальника (APPROVED) фиксируй рабочую фичу чистым git commit.
