## 3. ПРАВИЛА ВЛАДЕЛЬЦА (все действуют, не нарушать)
Дизайн:
- «Нейрослоп» = плоские тёмные плиты, неоновые полосы-отделки, одинаковые шаблонные карточки, мелкий серый текст, «стеклянные» градиенты, ДЕРЕВО, вещи без осмотра. Нужен стиль популярных Roblox-симуляторов (Steal a Brainrot, Grow a Garden и т.п.) и моих эталонов: насыщенные градиенты с бликом, ТОЛСТЫЙ чёрный контур у всего, крупные 3D-иконки, выступающие за край, толстый шрифт с обводкой, цвет = роль (зелёный = купить/играть, жёлтый = деньги, красный = закрыть/удалить), шипы и фаски на поверхностях, вертикальные ориентиры, яркое небо.
- **БЕЗ ДЕРЕВА нигде** (рамы, стойки, заборы, лидерборды…) — вместо дерева ЦВЕТНОЙ ПЛАСТИК: стойки красные (206,58,50), балки/основания тёмно-синие (46,58,110), рамы/рейки жёлтые (255,200,44), Material Plastic + шипы.
- **Магазины = компактные киоски как на референсах** (навес ~2 роста аватара), НЕ огромные павильоны. В КАЖДОМ магазине ОДИН NPC-продавец за прилавком, а не толпа NPC.
- Порядок любой визуальной работы: сделал → ОСМОТРЕЛ (назвал конкретные недостатки: место, признак, влияние, правка) → исправил → проверил в реальном размере → только потом загрузил/подключил → снова скриншот в игре. Дизайн без реальных скриншотов «до» и «после» не готов. Смотри на игру по ходу работы: если что-то большое, не так стоит или не так выглядит — меняй.
