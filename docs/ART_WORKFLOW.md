# Создание и приёмка моделей, текстур и оформления

Цель владельца — модели и оформление, которые соответствуют его референсам и хорошо выглядят в игре. Основной Claude выбирает инструменты, создаёт и исправляет. Chief проверяет результат и направляет исправления. Проверка может выявлять конкретные недостатки, окончательная оценка вкуса остаётся за владельцем.

## До изготовления

Открой подходящий референс и текущий объект в игре. Запиши в карточке задачи пять коротких строк

1. Что создаём, его роль и ID узла дерева.
2. Референс и 3–5 наблюдаемых признаков (силуэт, пропорции, цветовые роли, фактура, подача текста).
3. Габариты в studs, размер относительно аватара, расстояние игровой камеры и ограничения коллизии.
4. Способ изготовления и почему он подходит форме.
5. Как выглядит готовый результат и чем это проверяется.

Делай эту карточку сам из доступных правил и эталонов. Для неизвестной формы допустимо сделать маленький пробный вариант. Для масштабного редизайна без подходящего референса сначала уточни направление у владельца. Небольшие обратимые решения принимай самостоятельно.

## Выбор инструмента

| Задача | Способ работы |
|---|---|
| Простая блочная архитектура, studs, площадки, рабочие коллизии | Studio Parts и существующие строительные компоненты проекта |
| Сложный узнаваемый силуэт, механическая форма, аксессуар, фаски/скругления | Blender с моделированием, модификаторами и проверкой сетки |
| Развёртка, бесшовная текстура, запекание деталей/материалов | Blender UV и bake либо подходящая существующая текстура с проверенными условиями использования |
| 3D-иконка | Blender, существующий свет/камера/контур проекта, затем проверка PNG в размере кнопки |
| NPC и продавец | Настоящий Roblox-аватар и каталог одежды по правилам проекта; Blender для оправданных отдельных деталей |
| UI | Существующий UIKit и компоненты, согласованный стиль и свежий кадр в игре |
| Подходящий готовый ассет | Проверить форму, стиль, права/источник и содержимое, записать в ASSET_REGISTRY |

Применение инструментов выбирается по задаче. Для моделирования доступны blender-skills:blender-modeling-modifiers, для материала blender-skills:blender-shader-nodes, для экспорта и рендера blender-skills:blender-scene-rendering, для автоматизации blender-skills:blender-python-scripting. Загружай только нужное. При доступном Blender MCP сначала инспектируй сцену, затем изменяй и проверяй. При недоступном MCP используй установленный Blender CLI с воспроизводимым скриптом.

## Порядок работы

1. Сначала силуэт и пропорции. Сверь форму с референсом из сопоставимого ракурса и с масштабным ориентиром. Декоративные детали добавляй после этой самопроверки.
2. Сделай один законченный образец серии. Проверь цвет, материалы и характерные детали, сохрани исходник. Низкого разрешения предпросмотра достаточно для промежуточной проверки формы.
3. Импортируй образец в Studio и проверь в сцене игрока. На этот этап приходится обычное первое ревью chief. Раннее отдельное ревью силуэта нужно только при явном риске дорогой переделки.
4. Исправь главную причину замечаний, после неё переходи к менее заметным. При повторении того же дефекта сравни варианты до/после, назови причину и смени конкретную операцию, способ моделирования либо подходящий источник ассета. На обычную правку требуется один обоснованный вариант.
5. Развивай принятую модель в серию, сохраняя согласованный стиль. Проверяй отличающиеся силуэты и важные состояния. Повторно используй камеру, освещение, материалы и неизменившиеся референсы.
6. Финальную проверку выполняй с актуальными материалами, игровым светом, камерой и устройством. После приёмки синхронизируй исходники, экспорт, доказательства и дерево, сделай commit/push.

## Blender → Roblox

- Сохраняй редактируемый .blend и используемые текстуры/скрипт в assets/. Для экспорта создавай отдельный файл. Экспортируй предназначенные для игры объекты, проверяй применимость модификаторов, трансформации, pivot, нормали и масштаб.
- Для сетки проверяй швы, вывернутые поверхности, затенение, лишнюю геометрию, количество объектов и стоимость деталей на расстоянии камеры. Бюджет выбирай по размеру объекта на экране и количеству копий в сцене. Фиксируй измеренные значения, не вводи выдуманные универсальные лимиты.
- Для текстур проверяй UV, плотность деталей, растяжение, повторяемость, стыки и альфа-края. Цветовые и служебные карты должны использовать подходящую обработку цвета. Процедурные материалы при необходимости запекай в поддерживаемые карты. Проверяй назначение карт после импорта.
- Формат и параметры экспорта выбирай по актуальным требованиям Studio. Сначала импортируй один экземпляр и сверь размеры в studs, оси, цвета, прозрачность и SurfaceAppearance. После импорта повтори визуальную проверку в реальной сцене.
- Для игровых объектов сравнивай визуальную оболочку с реальными коллизиями, точками крепления и опасными зонами. Изменение массы, размеров или коллизий требует соответствующего теста NPC/игрока.
- Для иконок используй единый стиль проекта, проверяй прозрачный фон, края, контур и силуэт на настоящей кнопке. Для тайлов сделай предпросмотр повторения и затем проверь на игровой поверхности.
- После любой смены сетки/текстуры предыдущие доказательства для этого ассета считаются устаревшими. Сохраняй минимально достаточный свежий кадр и результаты применимых тестов.

Требования к экспорту и картам сверяются по официальной документации. [Экспорт](https://create.roblox.com/docs/art/modeling/export-requirements), [сетки](https://create.roblox.com/docs/art/modeling/specifications), [текстуры](https://create.roblox.com/docs/art/modeling/texture-specifications).

## Критерий остановки

Объект узнаваем по силуэту, соответствует выбранным признакам эталона, читается на игровом размере, вписывается в сцену, прошёл импорт и применимые проверки поведения. Существенные замечания закрыты. После этого переходи к следующему узлу дерева. Идеальная оценка по произвольной шкале и бесконечные косметические проходы не нужны.
