## 3. ПРАВИЛА ВЛАДЕЛЬЦА (все действуют, не нарушать)
Дизайн:
- «Нейрослоп» = плоские тёмные плиты, неоновые полосы-отделки, одинаковые шаблонные карточки, мелкий серый текст, «стеклянные» градиенты, ДЕРЕВО, склеенные из блоков «аксессуары», вещи без осмотра. Нужен стиль популярных Roblox-симуляторов и моих эталонов: насыщенные цвета, ТОЛСТЫЙ чёрный контур, крупные 3D-иконки, толстый шрифт с обводкой, цвет = роль (зелёный = купить/играть, жёлтый = деньги, красный = закрыть/удалить), studs («шипованный кирпич») на поверхностях, яркое небо.
- **БЕЗ ДЕРЕВА нигде** — вместо него цветной пластик: стойки красные (206,58,50), балки/основания тёмно-синие (46,58,110), рамы/рейки жёлтые (255,200,44), Material Plastic + studs.
- **Магазины = компактные киоски** как на эталонах (навес ~2 роста аватара), в КАЖДОМ магазине ОДИН продавец за прилавком.
- **Обучение = только стрелки**: дорожка стрелок на земле + стрелка над целью и у нужной кнопки с 1–2 словами. Никаких карточек и окон с текстом. Опытные игроки обучения не видят.
- Порядок любой визуальной работы: сделал → ОСМОТРЕЛ (место, признак, влияние, правка) → исправил → проверил в реальном размере → только потом подключил → снова скриншот в игре. Проверять ПК, телефон (альбом и портрет), iPad; в конце эмулятор вернуть на default.
- Принятый стиль UI (UIKit v2, плитки HUD, окна, верхние плашки) — не переделывать, править точечно теми же компонентами.
Игровые решения (сделаны — сохранять):
- Верхние кнопки Shop | Home | NPC Shop — только телепорт; окно магазина открывается у прилавка. Пока открыто любое окно, верхний ряд, хотбар и меню прячутся (окно модальное).
- Хотбар: слот 1 молоток, слоты 2–9 предметы, последний Delete. **Стройка**: ловушка «магнитом» встаёт вплотную к концу трассы и по её направлению; призрак зелёный = стыкуется, голубой = встанет отдельно, красный = нельзя. Это была моя главная жалоба («нельзя состыковать») — после любых правок стройки проверь стыковку сам мышью.
- Забег PLAY: только первое лицо, одна кнопка Exit, старт лицом к трассе.
- NPC и продавцы — настоящие Roblox-аватары в одежде из каталога (бесплатные вещи Roblox). ВАЖНО: на серверном NPC каталожных аксессуаров НЕТ (портили физику) — причёски клиент надевает сам (`NPCRig.DressLocal`).
- Табличка PLAY + полоса оценок; щит COURSE SAVES с 3 слотами.
Ассеты:

## 4. КАК РАБОТАТЬ СО STUDIO (уроки, экономят время)
- **Безопасные тесты «нового игрока» и стендов:** атрибут `ServerStorage.DevFreshProfile = true` → каждый Play = новый профиль в памяти, НИЧЕГО не сохраняется (мой тестовый профиль не портится). После тестов вернуть false. Никогда не менять настоящий профиль стендом.
- 3D-`screen_capture` работает в Play, когда окно «Лаборатория ловушек» впереди: вывести вперёд PowerShell `ShowWindow(hwnd,3)` + `SetForegroundWindow` по процессу RobloxStudioBeta с «Лаборатория» в заголовке. `screen_capture` НЕ рисует Beam, BillboardGui и Highlight — для них смотри настоящий экран (computer-use, Roblox Studio разрешён, tier full). Камеру задавать параметрами `camera_position`/`look_at_position`.
- При входе на моём профиле само открывается окно «Daily Gift» — закрывай его кнопкой Close (не забирай подарок за меня).
- Скрипты правятся только в Edit; во время Play `script_read` не видит серверные скрипты (читай `.Source` через execute_luau в Server). `require` из execute_luau = отдельный экземпляр модуля; для живых сервисов в Play создавай временный Script `ZZ_*` в ServerScriptService. Все `ZZ_*` в конце удалить.
- После правки большого модуля (ObstacleModels и др.) проверь сборку клоном: `require` клона и `build` всех 27 препятствий — так ловятся синтаксические ошибки (были: комментарий проглотил `end` и половину таблицы цветов).
- Beam с `Segments = 1` не рисуется; Highlight под `workspace.CurrentCamera` не рисуется.
- ЗАПЕЧЁННОЕ: «Зал», магазины (защищены атрибутом `HandEdited`, D-038), таблички участков. Правка их кода без перепекания в игру не попадает; перепекание откатит ручные правки (studs-проход и т.п.).
- Ввод: `user_mouse_input` — курсор смещён на +58 px по Y; `user_keyboard_input` (1–9, X, E, R). Device Emulator: сначала `SetDeviceAsync`, потом ориентация, всё ДО Play; синтетические клики в эмуляторе телефона не нажимают кнопки.
- Поиск бесплатных вещей каталога: `AvatarEditorService:SearchCatalog` (клиент в Play, CreatorName = Roblox, MaxPrice = 0); загрузка `InsertService:LoadAsset` (работает и из Edit).
- Blender: `"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P скрипт.py` (скрипты в TRAP_LAB\assets).
