## Начни здесь
1. `PROJECT_GUIDE/README.md` → `02_STATUS.md` (что сделано и нет) → `03_CODE_MAP.md` (где код) → `04_WORKFLOW_AND_STANDARDS.md` (как работать и принимать).

## Важно про код
- Игра работает внутри места Roblox Studio (PlaceId 135937017652181), без Rojo. `place/` — выгрузка скриптов. Правка файла в `place/` НЕ меняет игру: переноси правки через доступный Studio MCP и сверяй экспорт. Если MCP недоступен, явно укажи, какие локальные правки ждут переноса.
- Все числа — `place/ReplicatedStorage/Configs/Balance.luau`; тексты ошибок — `Configs/Strings.luau`; сервер решает всё (монеты/покупки), remotes через `Net.handle` с лимитами из Balance.
- Не меняй размеры препятствий (ломает физику NPC) и цены доната (только с владельцем).

## Правила владельца (обязательны)
Цветной пластик со studs, толстый контур, цвет = роль. Дерево допустимо, когда подходит объекту и сцене; киоски с одним продавцом; обучение только стрелками; окна модальные; забег PLAY — первое лицо и одна кнопка Exit. Полностью — `PROJECT_GUIDE/01_GAME.md`.

## Приёмка без субагента
У Claude Code есть проверяющий `trap-lab-chief`. У тебя его нет — выполни два чекпоинта сам (после каркаса и после финала) по `docs/QUALITY_REVIEW.md` и чек-листу в `PROJECT_GUIDE/04_WORKFLOW_AND_STANDARDS.md`. Без кадра из игры визуал = NOT TESTED. Проверяй кадры и Runtime через Studio MCP. Если инструмент недоступен, запрашивай доказательства у владельца и ставь NOT TESTED до проверки.
