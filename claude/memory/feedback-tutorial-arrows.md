**How to apply:** onboarding/hints = arrows only: a path of bold arrows on the ground + a bouncing arrow above the world target with 1-2 words, and a bouncing arrow next to the UI button to press with 1 word. Hide the arrow where Roblox's own ProximityPrompt already shows the action. Remove steps instead of explaining them (e.g. auto-select the bought trap).
