# Для ассистента (Claude): как работать с этим репозиторием

Владелец создал этот репозиторий (2026-11-17), чтобы вся работа по TRAP LAB хранилась здесь и ничего не терялось между чатами.

## В начале каждого чата
1. `git pull` в локальном клоне `C:\Users\yarik\AppData\Local\Roblox\roblox-geme`.
2. Прочитать `claude/memory/MEMORY.md` и все файлы памяти, затем `docs/HANDOFF.md` (последний раздел) и самый свежий `docs/NEXT_CHAT_PROMPT_S*.md`.
3. Studio: `list_roblox_studios` → место «Лаборатория ловушек».

## В конце работы (и после каждой крупной части)
1. Обновить документы в `docs/` (HANDOFF, TASKS, TESTING_REPORT, отчёт сессии), при необходимости — память в `claude/memory/` (и в локальной папке памяти Claude).
2. Выгрузить скрипты места в `place/` (см. ниже), чтобы код в репозитории совпадал с местом.
3. `git add -A && git commit && git push`. Коммитить с адресом `301790371+gribtolik1237-bot@users.noreply.github.com` (личную почту владельца в публичный репозиторий не писать).

## Выгрузка скриптов места в `place/`
Код живёт внутри места Studio. Способ без расхода контекста: временный локальный приёмник (`python -I recv.py <repo>/place`, 127.0.0.1:8765) + `execute_luau` в Studio шлёт каждый скрипт `HttpService:PostAsync`. Нужен адрес `127.0.0.1` в HTTP-allowlist ассистента Studio (Assistant Settings → MCP Permissions) — это делает владелец, ассистент настройки безопасности сам не меняет.
Имена файлов: путь по дереву Studio, суффикс `.server.luau` (Script), `.client.luau` (LocalScript), `.luau` (ModuleScript).
