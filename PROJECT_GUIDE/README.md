# PROJECT_GUIDE — всё о TRAP LAB в одном месте

Эта папка — точка входа для любого ИИ-разработчика (Claude Code, ChatGPT Codex и др.) и для владельца. Прочитав её, можно понять игру, что сделано и что нет, и продолжить разработку без истории чатов.

| Файл | Что внутри |
|---|---|
| [01_GAME.md](01_GAME.md) | Что за игра, игровой цикл, все системы, экономика, правила владельца |
| [02_STATUS.md](02_STATUS.md) | Что сделано, что частично, что не сделано и не проверено; приоритеты |
| [03_CODE_MAP.md](03_CODE_MAP.md) | Где лежит код, архитектура, remotes, данные, как править и выгружать |
| [04_WORKFLOW_AND_STANDARDS.md](04_WORKFLOW_AND_STANDARDS.md) | Порядок работы, контроль качества (начальник), 10 стандартов, Blender, уроки |

## Быстрый старт (любой ИИ)
1. `git pull` в `C:/Users/yarik/AppData/Local/Roblox/roblox-geme`.
2. Прочитать по порядку: этот README → `02_STATUS.md` → `../docs/DEVELOPMENT_TREE.md` (живое дерево задач) → раздел LESSONS LEARNED в `../CLAUDE.md`.
3. Для конкретной задачи — нужные документы из `../docs/` (таблица в `03_CODE_MAP.md`).
4. Игра исполняется в Roblox Studio (место «Лаборатория ловушек», PlaceId 135937017652181). Код в `../place/` — выгрузка из места; правки делаются В МЕСТЕ через Studio MCP, затем выгрузка в `place/`.
5. После работы: обновить статус в `../docs/DEVELOPMENT_TREE.md` и `02_STATUS.md`, коммит и push (правила в `../claude/README.md`).

## Claude Code vs ChatGPT Codex
- **Claude Code** читает `../CLAUDE.md`, вызывает субагента-начальника `trap-lab-chief` (`../.claude/agents/`), работает со Studio и Blender через MCP.
- **Codex** читает `../AGENTS.md`. Субагента и Studio MCP у Codex может не быть: тогда он правит файлы в `place/`, а владелец (или Claude) переносит правки в Studio; приёмку Codex делает сам по чек-листу из `04_WORKFLOW_AND_STANDARDS.md` и честно пишет, что не проверено в игре.
