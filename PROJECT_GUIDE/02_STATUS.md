## Расхождения стандартов промта с игрой (решать по правилам владельца)
- Стандарт «Lighting.Technology = Realistic, Atmosphere Density 0.25–0.38» — сейчас яркий дневной симулятор (Density 0.07); менять только с образцом и согласием, не теряя яркость эталонов.
- «Умные боты, заполняющие сервер» — в игре NPC-испытатели трасс, а не боты-игроки; новых ботов не добавлять без решения владельца.
- «UI только Scale» — текущий UIKit использует Offset + UIScale (`UIKit.scaleFor`) и проверен; переписывать не требуется.
- Списки материалов с WoodPlanks — запрещено правилом «без дерева».
